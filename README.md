## 同样写“香港 VPS”，1Gbps 和 2Mbps 差 500 倍

带宽是这类产品里最容易被模糊处理的参数。三个已经核验过的例子摆在一起：

- Akile HKLite-Mini：端口 1Gbps，月流量 2.5TB
- 六六云 HK-CMI-normal：峰值 50Mbps，月流量 800GB
- 恒创 精品线路入门款：独享 2Mbps，流量无限

1Gbps 对 2Mbps 是 500 倍，就算拿六六云 150Mbps 的大带宽款来比，也是 75 倍。都是“香港 VPS”，能不能跑直播推流、能不能做文件中转，答案完全两样。2Mbps 满速下载大约 250KB/s，传一个 100MB 的文件要将近 7 分钟，只够跑轻量网页。

反过来，标称 1Gbps 说的是端口速率，不是保证带宽。共享端口在晚高峰能跑多少，取决于同一宿主机上其他用户的占用。下单前用官方 Looking Glass 或测试 IP 拉个大文件，比看参数表可靠。
